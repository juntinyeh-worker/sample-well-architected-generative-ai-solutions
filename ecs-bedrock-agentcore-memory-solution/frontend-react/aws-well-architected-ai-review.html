⚠️ Beta User Agreement

This Automated Scanning Agent requires a cross-account ReadOnly IAM Role to fetch real-time data from your target AWS account.

By using this beta site, you acknowledge and agree to the following:

  • All metadata fetched from the target account will be used solely for runtime analysis.
  • This beta site does not store any configuration data except the final report delivered through the agent.
  • Generated reports are stored in an S3 bucket and delivered via a presigned URL provided once on-the-fly. The link will not be stored in any form.
  • All generated reports will expire in 60 minutes and be automatically purged.
⚠️ Please check the box above to proceed.

This is an Autonomous Review Agent that helps you run AWS Well-Architected Framework Reviews. Currently supporting Security and Cost Optimization pillar assessments.

🔗 Prerequisites — Cross-Account Access

We need to deploy a ReadOnly IAM role in your target account to allow this assistant to scan it.

  • Sign-in your own AWS Account in a new browser tab
  • Make sure you have the permission to deploy CloudFormation stack and setup new IAM Role
  • Click the button below
🚀 Deploy ReadOnly Role (One-Click)
🔒 Security Assessment

Once you have ReadOnly Role ready, enter your prompt like this:

Scan account 123456789012 for a Well-Architected Security assessment
Scan account 456789123401 for Security Review
💰 Cost Optimization Assessment

Once you have ReadOnly Role ready, enter your prompt like this:

Scan account 123456789012 for a Well-Architected Cost Optimization

Replace 123456789012 with your actual AWS account ID. Results typically take 2-5 minutes.

Keep your browser open — a brief summary will appear in the task panel on the right, along with a link to download the detailed assessment report. The report link will not be retrievable after the browser is closed.
